# firewall

Configure firewalld from a simple rule syntax, and remove what the rules no
longer declare.

Each entry in `firewall_rules` becomes up to three firewalld objects: a custom
service carrying the ports, an ipset per kind of source address, and a rich rule
binding the two together. A rule that names no source address is opened to its
whole zone instead. Anything the simple syntax cannot express goes in
`firewall_extra` and is applied verbatim.

Pruning is on by default: custom services, ipsets, rich rules and zone services
that exist on the host but are not declared are removed. `firewall_keep` names
what pruning must leave alone, and `firewall_require_ssh` refuses to run at all
if nothing accounts for ssh — without it, the first run of an unrelated ruleset
closes the door behind you.

## Requirements

- firewalld on the managed host. The role installs it through
  `fedora.linux_system_roles.firewall`.
- ansible-core 2.16 or later.

## Example playbook

```yaml
- hosts: servers
  roles:
    - role: ohioit.roles.firewall
      vars:
        firewall_rules:
          # Open to the whole zone.
          - name: https
            port: 443/tcp

          # Reachable only from the campus networks, via an ipset and a rich
          # rule rather than a zone service.
          - name: McKee Power Meter
            port: 8080/tcp
            sourceip:
              - 10.0.0.0/8
              - 192.168.4.17

          # Keep ssh where it is, so pruning does not remove it.
          - name: ssh
```

## Layering

`firewall_rules`, `firewall_extra`, `firewall_keep` and `firewall` each have
`common_`, `group_` and `host_` layers, folded together lowest priority first:

```text
firewall_rules <- common_firewall_rules <- group_firewall_rules <- host_firewall_rules
```

Rules are merged by `name`, key by key, so a host layer can change one field of
a rule the common layer defined without restating the rest of it.

## Advanced mode

Set `firewall_advanced: true` to hand `firewall` to
`fedora.linux_system_roles.firewall` untouched. Nothing is generated, queried or
pruned.

| Variable | Description | Type | Required | Default |
